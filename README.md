## 🌟 1. VBK Zenith — Business & SaaS Platform

**Founder & Full-Stack Developer | Production Deployment**

[![Live Website](https://img.shields.io/badge/Live%20Website-VBK%20Zenith-00C853?style=for-the-badge&logo=vercel&logoColor=white)](https://vbk-zenith.vercel.app/)

**VBK Zenith** is a modern business and technology platform developed to showcase software development, AI/ML solutions, SaaS development, and business automation services.

I designed, developed, and deployed the platform with a responsive public website, secure administration system, database integration, and content management capabilities.

### 🛠️ Technology Stack

| Layer | Technologies |
|---|---|
| Frontend | Next.js, React, TypeScript |
| Styling | Tailwind CSS |
| Backend | Next.js Server-Side Features |
| Database | Supabase PostgreSQL |
| Authentication | Supabase Auth |
| Authorization | Role-Based Access Control |
| Deployment | Vercel |
| Version Control | Git & GitHub |
| SEO | Metadata, Sitemap, Robots.txt |

### ✨ Key Features

- 🌐 **Responsive Business Website** — Modern interface for showcasing services, projects, and company information
- 🔐 **Secure Authentication** — Login, registration, account activation, and password recovery flows
- 👥 **Role-Based Access Control** — Separate OWNER and EDITOR permissions
- 📊 **Admin Dashboard** — Centralized management interface
- 📝 **Content Management System** — Manage website services, projects, and blog content
- 📩 **Client Inquiry Management** — Manage incoming business inquiries
- 💬 **Admin Chat** — Internal communication functionality
- 👨‍💼 **Team Management** — Administrative team access and management
- 🔍 **SEO Management** — Configurable SEO content, metadata, and indexing files
- 📜 **Change History** — Administrative activity and change tracking
- ⚙️ **Settings Management** — Platform configuration interface
- ☁️ **Production Deployment** — Deployed on Vercel with environment-specific configuration

### 🏗️ Platform Architecture

```text
                 VBK ZENITH
                      |
            Next.js Application
                      |
          +-----------+-----------+
          |                       |
    Public Website           Admin Portal
          |                       |
   Services / Projects       Authentication
   Blog / Contact                 |
          |                 Role-Based Access
          |                       |
          |                 OWNER / EDITOR
          |                       |
          |                 Admin Dashboard
          |                       |
          +-----------+-----------+
                      |
                Supabase
                      |
           PostgreSQL Database
                      |
              Vercel Hosting
```

- Developed reusable frontend components and responsive pages

- Implemented administrative access controls
- Built management interfaces for website content

- Configured sitemap, robots.txt, and SEO metadata

## 🧾 5. AI-Assisted Customer Complaint Management

An AI-assisted complaint management system designed for pharmaceutical manufacturing Quality Management Systems (QMS).

The system processes customer complaints from email, PDF, or text, extracts structured information, checks completeness, classifies risk, and prepares summaries for human review.

**Tech Stack:** AI, NLP, Full-Stack Development, AI Agent

### Workflow

```text
Customer Complaint
  (Email / PDF / Text)
          |
          v
AI Information Extraction
          |
          v
Completeness Validation
          |
          v
Risk Classification
          |
          v
AI Complaint Summary
          |
          v
Auto-Populated Form
          |
          v
Human Review & Submission
```

### Key Capabilities

- AI-powered complaint information extraction
- Email, PDF, and text processing
- Completeness validation
- Risk classification
- Automatic form population
- AI chat assistant for follow-up questions
- Structured complaint management
